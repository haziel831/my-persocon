# My Persocon — v1.9.11

## Animações de corpo a corpo

### O rig (inspecionado antes de escrever qualquer animação)

Os modelos da Persocon são Yes Steve Model / Bedrock (`main.json` + `main.animation.json`). A hierarquia de ossos:

```
Root
└ AllBody
  ├ UpBody  (tronco, pivô 0, 20.6, 0)
  │ ├ AllHead → Head (0, 33.8, 0) → Eyelids · HairBack (→ HairPhysR/L1..4) · EarUnits
  │ └ Arm (0, 31.2, 0)
  │   ├ RightArm  (-5.1, 30.6, 0) → RightForeArm  (-5.1, 24.8, 0) → RightHandLocator
  │   └ LeftArm   ( 5.1, 30.6, 0) → LeftForeArm   ( 5.1, 24.8, 0) → LeftHandLocator
  └ DownBody (0, 20.6, 0) → SkirtFront · SkirtBack · Leg (0, 21, 0)
      ├ RightLeg (-2, 21, 0) → RightLowerLeg (-2, 11.7, 0) → RightFoot (-2, 2.5, 0)
      └ LeftLeg  ( 2, 21, 0) → LeftLowerLeg  ( 2, 11.7, 0) → LeftFoot  ( 2, 2.5, 0)
```

Eixos (de `model.js` e `animation.js`): o modelo olha para **-Z** (o `view.js` gira com `YAW.front = PI`). O canal de rotação é `[pitch(x), yaw(y), roll(z)]` em graus e entra como
`final.x = rest.x − rx`, `final.y = rest.y − ry`, `final.z = rest.z + rz` (Euler ZYX). Portanto, neste rig:

| valor | o que acontece |
|---|---|
| `rx < 0` | o membro (que pendura para baixo) vai para **frente** (−Z); o tronco/cabeça (acima do pivô) inclina para **trás** |
| `rx > 0` | o membro vai para trás; o tronco/cabeça inclina para frente (queixo para baixo) |
| `ry > 0` | o tronco gira para a **direita**; o braço direito aponta para fora |
| `ry < 0` | o tronco gira para a esquerda; o braço direito aponta para dentro |
| `rz > 0` | o membro direito rola para fora (o esquerdo para dentro) |
| posição | `y+` para cima, `z+` para **trás** (a personagem olha para −Z), `x−` para a direita dela |

O `main.animation.json` do modelo **não foi tocado**: as animações novas são geradas pelo app (como as de `genanims.js`), então funcionam em qualquer modelo com os ossos padrão.

### As oito animações

| clip | duração | frame do golpe | o que acontece |
|---|---|---|---|
| `combat_idle` | 1,2 s (loop) | — | Postura de luta: joelhos dobrados, tronco a 25° de lado, as duas mãos na guarda, respiração e balanço sutis |
| `attack_jab` | 0,35 s | **120 ms** | Jab rápido com a **esquerda**, giro leve do tronco e passo à frente |
| `attack_cross` | 0,45 s | **180 ms** | Cross com a **direita**, com giro grande de quadril e ombro |
| `attack_uppercut` | 0,65 s | **280 ms** | Agachamento profundo, uppercut com a direita e salto |
| `attack_roundhouse_kick` | 0,60 s | **250 ms** | Tronco para trás e a perna direita varrendo num arco horizontal |
| `combat_block` | 0,16 s (fica no último frame) | — | Braços cruzados apertados na frente do rosto, cabeça abaixada, corpo travado |
| `combat_dodge_step` | 0,40 s | — | Salto lateral rápido com o centro de gravidade baixo |
| `combat_hit_stagger` | 0,45 s | — | Empurrão: cabeça e tronco para trás, braços se debatendo, depois volta |

Cada uma tem as três fases: **antecipação** (o braço recolhe, o corpo enrola), **golpe** (o frame exato do impacto) e **recuperação** (a volta à guarda). A interpolação é Catmull-Rom (o `animation.js` já suporta `lerp_mode`), o que dá o "estalo" do golpe com um leve overshoot.

### Controlador

`Combat` (`combat.js`) entra na Persocon (`pet.combatAnim`):

- `pet.playAnimation('attack_jab')` — toca qualquer animação; as de combate passam pelo controlador.
- `pet.chainAttack()` — emenda a corrente quando a janela do combo está aberta.
- `pet.combatAnim.update(dt)` (no laço da Persocon) — dispara o evento **`combatHit`** no frame do golpe (dano, efeito e som) e, no fim de um golpe, volta sozinha para a **postura de luta** (ou para a `idle` normal, fora do combate).
- `pet.combatAnim.canChain` / `chainNext()` — a janela de combo.

### Prévia (debug)

Opções → Debug → **Combate**: um botão por animação (com a duração e o frame do golpe na dica), o botão de ligar o modo combate e a prévia do soco. A prévia toca o clip e dispara o `combatHit` no tempo certo, para dar pra ver o efeito.

`genanims.js` não achava o tronco dos modelos YSM: o osso se chama `UpBody` e o gerador só conhecia `UpperBody`/`Body` (o resto das animações geradas rodavam sem mexer no tronco). Agora `UpBody` também é reconhecido.
